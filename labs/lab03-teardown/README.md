# Lab 3 — Teardown and the command line

## 1. The machine
*   Exact Model: X133-ADN (Manufacturer: CORE-SHARP)
*   How I found it: Used PowerShell command Get-CimInstance Win32_BaseBoard and Win32_Processor. Found X133-ADN with an Intel N95 CPU.
*   Manual Link: This is an unbranded whitebox laptop. No official manual exists. As permitted by the brief, I used a generic teardown reference for N95 laptops.

## 2. Components
*   Memory: SO-DIMM slot. Connects to CPU. Limits: OS shows FormFactor: 12 (not soldered), currently holding 16GB.
*   Storage: M.2 slot. Connects to chipset. Limits: 512GB ShiJi SATA SSD.
*   Cooling: Fan and heatsink. Connects to CPU. Limits: Limits sustained heavy workloads.

## 3. Upgrade verdict

| Component | Manual says | OS says | Verdict |
| :--- | :--- | :--- | :--- |
| Memory | Generic N95 board: 1 slot. | 16GB, SODIMM (FormFactor: 12). | Yes: Socketed, can be replaced with a larger SODIMM. |
| Storage | Generic N95 board: 1x M.2 slot. | 512GB, SATA interface. | Yes: Can be replaced with a larger M.2 SATA drive. |
| CPU | Generic N95 board: BGA. | Intel(R) N95. | No: The N95 CPU is a BGA chip soldered directly to the board. |

Disagreement explanation: Because there is no official manual, I trust the OS command-line output for current state, and generic N95 architecture rules for limits.
